# Pragathi Pattar – Portfolio

A modern, responsive personal portfolio website showcasing work in Operations, Business & Data Analytics, and Product Management.

## Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Animations & UI:** Framer Motion, Lucide Icons, Swiper
- **Visualizations:** Recharts

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

1. Clone the repository and navigate to the project directory:
   ```bash
   cd "Folio 2"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Preview Production Build

```bash
npm run preview
```
